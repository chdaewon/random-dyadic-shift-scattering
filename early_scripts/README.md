# Early scripts (Figures 1 and 2)

Run in this folder, in this order:

```
python mult.py           # MT_haar.npy: averaged Haar multiplier m_T
python e1_discrete.py    # e1.npy: discrete implementation (Figure 1, circles)
python e2_transl.py      # e2.npy: ||S_omega - S_omega+a|| (Figure 2, left)
python e3_deform.py      # e3.npy: first deformation experiment (superseded by paper_final/fig3)
python e9.py             # e9_int.npy: Hilbert-coefficient integrand (Figure 2, right)
python figs_en.py        # fig1_en.pdf, fig2_en.pdf, fig3_en.pdf, fig4_en.pdf
```

`figs_en.py` also draws a first version of Figure 3. The published Figure 3 is produced by `paper_final/fig3/`.

The remaining scripts are implementation checks:
- `e4_misc.py`–`e7b.py`: truncation bias, dilation-quadrature ripples, comparison with the discrete Hilbert transform, and further shift checks.
- `align.py`, `align2.py`, `e8.py`: the child-offset alignment of Section 3 (`e8.py` is also imported by `e9.py`).

`.npy` files are not stored in the repository; they are regenerated by the commands above.
